📦 Online Order Management System

A Java-based application for managing online customer orders and tracking delivery status.

🚀 Features

- Add and manage customer orders.
- Track orders using tracking numbers.
- Search orders by customer name.
- Calculate estimated delivery dates.
- Update delivery status.
- View order status history.

🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Java LocalDate API

📁 Project Structure

- "CustomerOrder.java" – Base order class.
- "OnlineOrder.java" – Online order and tracking functionality.
- "OrderManager.java" – Order management and searching.
- "Main.java" – Main application entry point.

▶️ How to Run

1. Clone this repository.
2. Open the project in your Java IDE.
3. Run "Main.java".
